## Overview

`hr-leave-management` is a full-featured HR system that streamlines employee leave requests, approvals, and organizational workflows through a robust backend and a dynamic frontend interface. Designed for developers, it emphasizes security, modularity, and user-centric features to support HR teams and employees alike.

### Why hr-leave-management?

This project simplifies HR operations with a focus on security, scalability, and usability. The core features include:

* 🔒 **Role-Based Access**: Ensures secure, permission-driven navigation tailored to user roles.
* 📄 **User Story Templates**: Facilitates consistent documentation of requirements and acceptance criteria.
* 📊 **Real-Time Dashboards**: Provides insightful metrics and analytics for organizational oversight.
* 🧩 **Modular Architecture**: Supports flexible HR workflows like leave management, employee directory, and attendance.
* 🔐 **JWT Authentication**: Implements secure, stateless user authentication for seamless access.
* 🎨 **Rich UI Components**: Offers a responsive, maintainable interface built with Angular Material and reusable components.

## Getting Started

Follow these steps to set up and run the project locally.

### Prerequisites

This project requires the following dependencies:
* **Programming Language**: TypeScript
* **Package Manager**: Npm, Maven

### Installation

Build `hr-leave-management` from the source and install dependencies:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/GutsDCEO/hr-leave-management](https://github.com/GutsDCEO/hr-leave-management)
    ```

2.  **Navigate to the project directory:**
    ```bash
    cd hr-leave-management
    ```

3.  **Install the dependencies:**
    * Using **npm**:
        ```bash
        npm install
        ```
    * Using **maven**:
        ```bash
        mvn install
        ```
